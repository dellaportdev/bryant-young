Legacy game live server browser

What it is
A real-time server browser for Starsiege: Tribes (1998) on clanorb.com. It queries game servers directly over UDP and provides a real-time recreation of the in-game server browser.
My role
Sole developer. UI, UX and CSS built by hand. Used AI to reverse engineering query protocols from the original game files.
Highlights
  • Pixel-accurate recreation of the in-game server browser, using the original fonts, cursors, icons and sounds, plus a mobile-responsive layout.
  • Server list parsing built on a reverse-engineered UDP protocol from a decades-old codebase.
  • PostgreSQL-backed cache for fast response times.
  • Local REST API that reshapes incoming data for the frontend and doubles as an embeddable service for outside websites.
  • Accessible dialogs and full keyboard navigation.
Tech
TypeScript SvelteKit Node.js PostgreSQL SCSS Tailwind

Constant Contact OAuth Integration

What it is
An API client and admin page that adds new storefront customers to Constant Contact mailing lists. Includes manual entry, OAuth re-authorization, and a paginated log of every API call.
My role
Sole developer for a freelance client.
Highlights
  • OAuth 2.0 authorization-code flow: session-checked state parameter, token exchange, and refresh tokens stored in the database.
  • REST integration over cURL with error handling. Expired access tokens refresh automatically and the failed request retries once.
  • Every call is logged and shown in the admin as a readable history with status and error details.
  • Server-rendered PHP templates with logic kept out of the markup, plus accessible forms and tables.
Tech
PHP MySQL OAuth 2.0 REST API Tailwind
